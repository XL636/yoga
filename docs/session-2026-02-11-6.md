## 知识点记录

### DNS 解析 vs 服务器域名绑定
- DNS 解析（DNSPod）：域名 → IP 的映射，让全球用户能找到服务器
- 服务器域名绑定（腾讯云控制台）：服务器级别的域名关联，方便后续一键申请 SSL 证书等操作
- 两个都要配，互不替代

### SSL 证书
- 让网站从 http 变成 https，数据传输加密
- 微信小程序强制要求 HTTPS，没有 SSL 证书小程序无法调用后端 API
- 腾讯云提供免费 SSL 证书，备案通过后在控制台一键申请

### 子域名的作用
- `api.hongbeyuan.cn`：后端 API，小程序调用的接口（返回 JSON 数据）
- `admin.hongbeyuan.cn`：管理后台网页，浏览器打开用于排课和管理预约
- `www` / `@`：官网用，目前不需要
