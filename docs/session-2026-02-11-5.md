## 知识点记录

### 为什么需要 .env 文件
- 把密码、密钥从代码中分离出来，代码可以公开（GitHub），密钥只在服务器上
- 三个关键配置：JWT_SECRET（防伪造身份）、ADMIN_PASS（防后台被入侵）、WX_SECRET（微信登录验证）

### 服务器和本地电脑的关系
- 两台独立的机器，通过 Git 同步代码
- .env 不通过 Git 传输，只在服务器上手动创建
- 本地开发用默认值，服务器用正式值

### DNS 解析的作用
- 把域名翻译成 IP 地址
- 小程序 → api.hongbeyuan.cn → DNS → 106.53.70.74 → Nginx → Node.js(3000)

### 备案类型选择
- 网站/域名备案：用于网站、API 服务器
- App 备案：用于独立 iOS/Android 应用
- 微信小程序不算 App，走微信自己的审核
